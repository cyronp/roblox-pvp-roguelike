## Getting Started

To build the place from scratch, use:

```bash
rokit install
wally install
rojo build -o "Test.rbxlx"
```

The ammo display uses React Luau. Run `wally install` after cloning or changing
`wally.toml` so Rojo can sync the packages into `ReplicatedStorage`.

`Test.rbxlx` is a snapshot of the project at build time. Run this command
again before reopening the file if you want it to contain the latest changes.

Next, open `Test.rbxlx` in Roblox Studio and start the Rojo server:

```bash
rojo serve
```

Connect to that server from the Rojo plugin in Studio. If you edit
`default.project.json` to add or remove mapped objects, restart `rojo serve`
so the server loads the new project tree. Restart Play in Studio to test
new character equipment or scripts.

`StarterPlayerScripts` is managed by Rojo. Add client scripts to the project
files; scripts added only in Studio under that service are removed on sync.

For more help, check out [the Rojo documentation](https://rojo.space/docs).

## Revolver firing audio

The original gunshot is `assets/audio/revolver-shot.wav` (0.4 seconds, mono).
The uploaded sound is `rbxassetid://114169781286214`. The experience needs access
to this audio. See [Roblox's audio import guide](https://create.roblox.com/docs/audio/assets).

The asset ID is configured in
`tree.ServerStorage.Revolver.Handle.FireSound.$properties.SoundId` in
`default.project.json`.
Restart `rojo serve` after editing the project mapping, then restart Play;
or rebuild `Test.rbxlx` and reopen it.

The server plays the sound after accepting a shot. Each revolver reuses its own
sound, with volume 0.65 and distance attenuation from 12 to 180 studs.

## Kill confirmation and training dummy

Kill confirmation uses `rbxassetid://83811330659090`; grant the experience access
to this audio too. The server notifies only the shooter when their revolver hit
reduces a living target to zero health. Nonlethal hits, protected targets, and
shots at dead targets do not trigger the confirmation.

On Play, a stationary **Training Dummy** appears 24 studs in front of the first
SpawnLocation, facing it. With no SpawnLocation, it appears near `(0, 3, -24)`;
the script adjusts its height to the ground. It has 100 health, takes three
revolver hits to kill, and respawns after three seconds.

To verify in Studio, restart Rojo and Play, shoot the dummy three times, and
check that only the last hit plays the kill sound. Repeat after it respawns.
With two players, check that only the player landing the final shot hears the
confirmation. The same confirmation applies to player kills.
