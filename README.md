## Getting Started

To build the place from scratch, use:

```bash
rojo build -o "Test.rbxlx"
```

`Test.rbxlx` is a snapshot of the project at build time. Run this command
again before reopening the file if you want it to contain the latest changes.

Next, open `Test.rbxlx` in Roblox Studio and start the Rojo server:

```bash
rojo serve
```

Connect to that server from the Rojo plugin in Studio. If you edit
`default.project.json` to add or remove mapped objects, restart `rojo serve`
so the server loads the new project tree. Restart Play in Studio to test
new character equipment or scripts.

For more help, check out [the Rojo documentation](https://rojo.space/docs).
